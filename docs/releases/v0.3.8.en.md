# v0.3.8

## Highlights

- **Initial Android release**
  - Android build support via Tauri v2
  - Speech recognition via remote API (recog.falkoe.net) instead of local Whisper
  - IPA resources and MeCab dictionary bundled in the APK
- **AnkiDroid integration**
  - Add cards to AnkiDroid directly from the app on Android
- **Tatoeba audio author display**
  - Show the recorder's name for example sentence audio
  - Fall back to "unknown" so the credit field is never empty

## Android Limitations

- Audio Cutter is not available (requires local Whisper)
- MP4 export is not available

## Bug Fixes

- Fixed header audio not downloading on the recorder screen
- Fixed audio playback and recording issues
- Fixed ffmpeg-related issues
