# v0.3.5

## Highlights

- Audio Cutter（音声カット）画面を追加
  - Whisper で区間（セグメント）検出 → 取捨選択 → クリップを書き出し
  - 1行=1クリップの全文テキスト欄で、区間の結合/ラベル変更が可能
  - セグメントごとのプレビュー再生
- 区間検出の UX 改善
  - 検出中モーダル表示（進捗バー）
  - Whisper から実進捗を受け取り表示
  - キャンセルボタンで中断可能
- 安定性/パフォーマンス
  - Whisper のスレッド数を控えめにして、環境によって発生するエンコード失敗（error code: -6）を起きにくく

## Notes

- 区間検出中は操作が重くならないよう UI をロックし、進捗とキャンセル導線を出します。
- 必要に応じて `FALKOE_WHISPER_THREADS` でスレッド数を調整できます。
