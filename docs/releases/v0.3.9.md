## ⚠️ macOS での注意 / Gatekeeper

macOS 版はアドホック署名のみです。Apple 公証はしていないため、Chrome などからダウンロードしたアプリは初回起動時に Gatekeeper によりブロックされることがあります。

もし次のようなメッセージが出たら、**ゴミ箱には入れず「完了」** を押してから、続けて次のコマンドを実行してください。

> 「開いていません。Apple は、…マルウェアが含まれていないことを検証できませんでした。」

```bash
xattr -dr com.apple.quarantine /Applications/Falkoe.app
```

もし「壊れているため開けません」と表示される場合は、署名が無効な可能性があるため、まず署名を付け直してから隔離属性を消します。

```bash
codesign --force --sign - /Applications/Falkoe.app
xattr -dr com.apple.quarantine /Applications/Falkoe.app
```

## インストール方法

1. Releases から `.dmg` をダウンロードして開く
2. `Falkoe.app` を `Applications` にドラッグ
3. `Applications` から起動

もし `.dmg` が使えない場合は、`Falkoe.app` をダウンロードして `Applications` に移動して起動してください。
