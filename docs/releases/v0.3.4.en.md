# v0.3.4

## Highlights

- Batch import for audio files (process multiple files sequentially in a queue)
- Smoother importing UI for large selections (lighter queue/progress updates, filename search & prioritization)
- Confirm dialog when leaving the screen during import (prevents accidental queue reset)
- Search and sort in History (text / filename / ID, timestamp / takes, etc.)
- Preserve and display the original filename for uploaded audio in History (`original_filename.txt`)
- Remove i18n `{{var}}` placeholders; build dynamic strings in TypeScript instead

## Notes

- History search targets: text / filename / language / audio ID (case-insensitive substring match)
- Sorting is done on the frontend; empty fields are pushed to the end
- Leaving the screen during batch import would drop the remaining queue, so a guard confirmation is shown
