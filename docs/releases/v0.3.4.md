# v0.3.4

## Highlights

- 音声ファイルの一括取り込み（複数ファイルをキューで順次処理）
- 大量ファイルでも固まりにくい取り込みUI（キュー/進捗の軽量化、検索・優先操作）
- 取り込み中に別画面へ移動しそうな場合は確認ダイアログを表示（キューの意図しないリセット防止）
- 履歴一覧で検索・ソートに対応（テキスト/ファイル名/ID、録音日時/テイク数など）
- 履歴でアップロード音声が識別しやすいよう元ファイル名を保存して表示（`original_filename.txt`）
- i18n の `{{var}}` プレースホルダを撤去し、動的文言はTS側で組み立てる方針へ移行

## Notes

- 履歴の検索対象: テキスト / ファイル名 / 言語 / 音声ID（部分一致・大文字小文字無視）
- ソートはフロント側で実施し、未入力（空）項目は末尾寄せになります
- バッチ取り込み中に画面遷移すると未処理キューが失われるため、ガードで確認を挟みます
