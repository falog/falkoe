## ⚠️ macOS notice / Gatekeeper

The macOS build is ad-hoc signed only. It is not notarized by Apple, so apps downloaded via Chrome or similar browsers may be blocked on the first launch by Gatekeeper.

If you see a message like:

> “This app is damaged and can’t be opened” or “Apple could not verify the app is free of malware.”

click **Done** without moving it to the Trash, then run:

```bash
xattr -dr com.apple.quarantine /Applications/Falkoe.app
```

If the app says it is damaged, the signature may be invalid. Re-sign it first, then remove the quarantine flag:

```bash
codesign --force --sign - /Applications/Falkoe.app
xattr -dr com.apple.quarantine /Applications/Falkoe.app
```

## Install

1. Download the `.dmg` from Releases and open it
2. Drag `Falkoe.app` into `Applications`
3. Launch it from `Applications`

If a `.dmg` is not available, download `Falkoe.app` (or an archive containing it) and move it into `Applications` before launching it.
