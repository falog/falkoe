# v0.3.6

## Highlights

- Better flow from Audio Cutter → Practice (sentence)
  - The "Import" button now brings clips into the practice flow instead of only exporting files
  - Imported clips are persisted under sentence history and the practice screen opens immediately
- Simplified Audio Cutter options
  - Removed "Re-analyze (no merging)" and "Detect per-word segments (experimental)" for now to keep the primary workflow simple
- Improved History discoverability
  - Filter dropdown (All / Uploaded only / Examples only / Audio cut only)
  - Prefer filename in card titles
  - Make the body text (sentence) more prominent

## Notes

- Audio Cutter "Import" internally copies exported clips into `$DOCUMENTS/falkoe/sentences/<id>/uploaded/`.
- "Audio cut only" is based on a tag automatically applied to clips imported from Audio Cutter.
