# v0.3.7

## Highlights

- Linking display now preserves the input casing
  - Prevents the first letter from being lowercased automatically
- Number pronunciation support in linking display
  - Supports 2/3/4-digit numbers, comma-separated groups (e.g. 999,999,999), and scales up to million/billion/trillion
  - In year-like context, prefers readings like 2026 → "twenty twenty six"
- Improved debug logging
  - Captures full stdout/stderr from external tools (whisper / ffmpeg / MeCab / Praat / WORLD) into backend.log

## Notes

- ffmpeg prints normal logs to stderr by design (stderr does not necessarily mean an error).
- If logs become too large, you can tune rotation settings:
  - `FALKOE_LOG_ROTATE_MAX_BYTES`
  - `FALKOE_LOG_ROTATE_KEEP_FILES`
- To also mirror logs to the terminal, set `FALKOE_LOG_STDERR=1`.
