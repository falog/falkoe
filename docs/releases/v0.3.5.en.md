# v0.3.5

## Highlights

- Add an Audio Cutter screen
  - Detect segments with Whisper → select → export clips
  - Full-text editor (1 line = 1 clip) to merge segments / relabel clips
  - Per-segment preview playback
- Better UX for long segment detection
  - Detecting modal with a progress bar
  - Show real progress reported by Whisper
  - Cancel button to abort detection
- Stability / performance
  - More conservative Whisper thread defaults to reduce occasional encoder failures (error code: -6) on some systems

## Notes

- While detecting segments, the UI is locked to keep the app responsive and to surface progress/cancel controls.
- You can override the thread count via `FALKOE_WHISPER_THREADS` if needed.
