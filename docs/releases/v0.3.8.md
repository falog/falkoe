# v0.3.8

## Highlights

- **Android 版の初期リリース**
  - Tauri v2 ベースで Android ビルドに対応
  - ローカル Whisper を使わず、リモート APIで音声認識
  - IPA 資料・MeCab 辞書を APK にバンドル
- **AnkiDroid 連携**
  - Android 上で AnkiDroid へカードを追加する機能を実装
- **Tatoeba 音声の author 表示**
  - 例文音声の録音者名を表示するようにした
  - 不明な場合も "unknown" と表示してクレジット欄が空にならないよう修正

## Android 版の制限事項

- 音声カット（Audio Cutter）は利用できません（ローカル Whisper が必要なため）
- MP4 エクスポートは利用できません

## Bug Fixes

- 録音画面の模範解答音声がダウンロードされなかった問題を修正
- 音声の再生・録音ができなかった問題を修正
- ffmpeg 周りの不具合修正
