# v0.3.3

## Highlights

- Tatoeba の例文/音声にクレジット（ライセンス/作者）を表示
- ライセンス情報が欠落している Tatoeba 結果は検索から除外
- クレジットリンクは WebView 内ではなく OS の外部ブラウザで開く
- 履歴から開いた場合もクレジットが復元される（manifest 永続化）
- 動画出力で「Model」黒画面にクレジットを焼き込み表示
- 動画内の改行を調整（例文タイトル/字幕/クレジット）

## Notes

- クレジットは Tatoeba API の `license/owner/audios[*].license/author/attribution_url` を元に表示します。
- 動画のクレジットは 2 行固定（`Sentence` と `Audio`）を想定しています。
