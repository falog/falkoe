# v0.3.6

## Highlights

- Audio Cutter（音声カット）→ 練習（sentence）への導線を改善
  - 「取り込み」ボタンが、クリップを書き出すだけでなく「練習に持っていく」動きになりました
  - 取り込んだクリップは履歴（sentences）に保存され、すぐ練習画面を開けます
- Audio Cutter のオプション整理
  - 「再解析（結合なし）」と「単語ごとに検出（試験機能）」を一旦削除し、基本動線をシンプルにしました
- 履歴（録音履歴）の見つけやすさ改善
  - 表示フィルタをセレクトボックス化（全体 / uploadedだけ / 例文検索結果のみ / 音声カットのみ）
  - カードの見出しをファイル名優先に
  - 本文（テキスト）をより目立つ表示に

## Notes

- Audio Cutter の「取り込み」は内部的に、書き出したクリップを `$DOCUMENTS/falkoe/sentences/<id>/uploaded/` にコピーして保存します。
- 「音声カットのみ」は、Audio Cutter 経由で取り込んだものを目印（タグ）で判別してフィルタします（表示名は「音声カット」に統一）。
