# v0.3.3

## Highlights

- Show Tatoeba sentence/audio credits (license/author)
- Exclude Tatoeba results that are missing license information from search
- Open credit links in the OS external browser instead of navigating inside the WebView
- Restore credits when opening from History (persisted in `manifest.json`)
- Burn credits into the black “Model” screen when exporting videos
- Adjust line wrapping in exported videos (sentence title/subtitles/credits)

## Notes

- Credits are derived from the Tatoeba API fields: `license/owner/audios[*].license/author/attribution_url`.
- Video credits are expected to be fixed to 2 lines (`Sentence` and `Audio`).
