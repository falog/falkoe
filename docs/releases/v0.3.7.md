# v0.3.7

## Highlights

- リンキング表示が入力テキストの大文字小文字を維持
  - 先頭が勝手に小文字化されないように改善
- 数字の発音（リンキング表示）に対応
  - 2桁/3桁/4桁、カンマ区切り（例: 999,999,999）、million/billion/trillion まで
  - 年号っぽい文脈では 2026 → "twenty twenty six" の読みを優先
- デバッグ用ログを強化
  - whisper / ffmpeg / MeCab / Praat / WORLD など外部ツールの stdout/stderr を backend.log に全量記録

## Notes

- ffmpeg は通常ログも stderr に出します（stderr=エラーとは限りません）。
- ログが大きくなりやすいので、必要に応じてローテーション設定を調整できます:
  - `FALKOE_LOG_ROTATE_MAX_BYTES`
  - `FALKOE_LOG_ROTATE_KEEP_FILES`
- ターミナルにもログを出したい場合は `FALKOE_LOG_STDERR=1` を設定してください。
